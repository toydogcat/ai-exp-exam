## 目標
1.  記錄國考題目的高品質轉換心得。
2.  提供非選擇題（填充、名詞解釋、申論、計算）的參考答案與深度解析。
3.  分享各類考科的學習地圖與 AI 輔助學習技巧。


## 內容結構
-   **出題單位/年份/考科**：每篇文章的統一命名格式。
-   **Jekyll Posts**：存放於 `_posts/` 目錄下。

## GitHub Pages 設定
請在 GitHub Repo 的 `Settings > Pages` 中：
1.  Source: **Deploy from a branch**
2.  Branch: **main** (或 master)
3.  Folder: **/(root)**
